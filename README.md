# CheckDraw

Sistema de conferência assistida de desenhos técnicos de engenharia (DWG/PDF): importação em lote, regras determinísticas, IA com evidência, marca-texto digital por região, controle de revisão e liberação auditada. Web (ASP.NET Core + Netlify + Supabase) e desktop (WPF).
